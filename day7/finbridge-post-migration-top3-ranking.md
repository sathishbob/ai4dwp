## Top 3 themes to act on today

### 1. AVD sign-in / account lockout
- Count: 7
- Why it ranks here: This is the highest-volume Blocker theme and stops users from working entirely, so it needs immediate attention before lower-impact issues.
- Manager line: We have a live access issue affecting seven users who cannot get into AVD, so this is the first fix to prioritize today.

### 2. OneDrive file access / sync issues
- Count: 4
- Why it ranks here: Fewer comments than the AVD issue, but it is still a Blocker because users are missing files they need for meetings and end-of-day work.
- Manager line: OneDrive problems are putting active work at risk because users cannot trust that critical files are available.

### 3. Shared drive access failure
- Count: 3
- Why it ranks here: It affects fewer users than the two issues above, but it is still a Blocker because it prevents completion of core finance work.
- Manager line: Shared drive access is blocking business tasks for a smaller group, but the operational impact is severe enough to keep it in the top three.
