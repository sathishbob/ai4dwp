# Self-Service Answers

## AVD sign-in / account lockout
Close the AVD window completely, wait 30 seconds, and try again using your full work email address and password. If it still fails, lock your keyboard and sign back in to Windows once, then retry AVD.

If you still cannot get in after two tries, contact the service desk. Tell them the exact time it failed, the message you saw on screen, whether you could sign in to Windows normally, and whether this happened more than once today.

## OneDrive file access / sync issues
Open OneDrive from the taskbar cloud icon and check whether it says signed in. If not, sign in with your work email. Then open the OneDrive folder in File Explorer and look for the missing file by name using the search box.

If the file is still missing or shows an error, contact the service desk. Tell them the file or folder name, when you last saw it, whether it is missing in File Explorer or the browser too, and take a screenshot of any warning message if possible.

## Shared drive access failure
Close File Explorer, reopen it, and try the shared drive again. If it still does not open, restart your laptop once and test the drive again after sign-in.

If the drive still will not open, contact the service desk. Tell them the drive letter or shared folder name, the exact message on screen, whether other folders open normally, and what work you are blocked from doing so they can set the priority quickly.
